═══ 第一件：壓平 ═══

一、它幾乎沒有新程式

flattenElements() 完全走現成的 elementBasis() + applyElementTransform()，
一行新的數學都沒有。因為「壓平」就是「縮放 x 法向 x Z 打 0」。

那是三個概念正交換來的第二個免費功能
（第一個是「沿法向推拉 = 移動 x 法向」，它讓 pushFace() 那條待辦消失）。
這顆按鈕存在的理由只是讓它按得到 —— 那個組合沒有人猜得到。
跟擠出的方案 C 同一個形狀。

二、壓平之後「併成一個面」是免費的

kang 想把 3 個 seg 變成一個面。直覺做法是「不管夾角直接併成一個 n 邊形」
（Blender 的溶解面）——

  實測那個 8 邊形偏離平面 0.9561 cm，是可切容許值（0.1mm）的 96 倍。

那不是「精確變近似」，是做不出來。
而壓平之後那幾片真的共面了，mergeCoplanarFaces() 就會自己併掉，
結果是一個真正平的面（不平度 2.3e-15），展開仍然精確。

所以 flattenSelected() 壓完自動再跑一次還原多邊形，並把選取搬到新的那個面。
⚠ remapElements() 因此要去重 —— 三個舊面全指向同一個新面，
不去重「選了幾個」會說 3 而畫面只有一個（坑第 20 條）。

三、✘ 溶解面（不共面的那種）明確不做

不是主觀判斷，是那個 96 倍。
溶解共面的面那就是還原多邊形，已經有了。
⛔ 不要因為 Blender 有就補上。

四、拿掉一道我自己加錯的防護

applyEditNumber() 有一行 if (num === 0) return false，
理由寫著「縮到 0 = 把面壓成零面積」。那個判斷錯了兩次：
沿法向縮到 0 不是壓成零面積、是壓平（完全合法）；
而且它是沉默地拒絕（坑第 11 條）。
「壓成零面積」本來就有人管：refreshAfterEdit() 會回報 degenerate。
程式沒資格替人決定做不做得出來。

五、兩個實作決定

toast 要講「壓平前偏離多少」—— 那是使用者付的代價，而且他自己驗得出來。
只講「壓平了」等於沒講：形狀變了多少他看不出來。

本來就平的面 -> 什麼都不做而且講一句，不記 Undo。
悶著記一步「什麼都沒改」，使用者會以為壞掉了。

═══ 第二件：kang 拉了一下，照出一個潛伏很久的 bug ═══

六、「為什麼會出現一個很奇怪的三角區域?」

他把壓平後那一片往內拉，上蓋變成非凸的 32 邊形。
而 toGeometry() 用扇形三角化，那只對凸多邊形成立 ——
上蓋一凹就有三角形跑到外面、繞向翻掉。

  真實面積 1798.39　扇形算出來 1880.34　多畫 81.95 cm²（4.56%）
  繞向翻掉的三角形 1 個

七、🔴 但它不只是畫面 —— 全專案有 8 個出口

mesh.volume()       有號體積          ✅ 對
mesh.area()         絕對值相加        🔴 多算 4.56%
mesh.toGeometry()   畫面              🔴 kang 看到的那塊
region.js           區域面積、重心    🔴 錯
stl.js              STL 匯出          🔴 翻掉的三角形 -> 切片軟體報非流形
flatten.js          展開片面積        🔴 多算 -> 備料會算錯
bool.js             送給 Manifold     🔴 布林拿到壞掉的實體
edit.js             判零面積          ⚠ 影響小

⚠ STL 體積照樣對得上（71935.55）—— 它是有號的，翻掉的三角形在裡面也不影響。
那正是坑第 17 條：中途的量一直都是對的，末端才錯。
要驗這件事就得逐個三角形問它的法向對不對，測試現在這樣做。

八、🔴 這個 bug 一直都在，是新功能讓它浮出來的

n 邊形本來只出現在 roundBox（20 邊形，凸）與 tube（四邊形），
而匯入的擠出件早就自己耳切成三角形了 —— 從來沒有非凸的 n 邊形。
「還原多邊形」讓每個共面區域都變成 n 邊形，編輯又能把它拉凹。

⭐ 這件事本身是新功能的價值：它把一個一直錯著沒人發現的東西逼出來了。

九、修法：一個入口，八個出口

鐵律一第 1 條先問「本專案有沒有解過同一個問題」—— 有。
extrude.js 的 earClip() 已經 export、已經測過。
⚠ 但 extrude.js 匯入 mesh.js，耳切留在那裡會循環依賴。

1. 抽出 core/triangulate.js —— 逐字搬，165 行 / 6215 bytes /
   md5 54e206726bd481859460e8bd16b13ae1，搬完對過。不匯入任何東西。
   extrude.js 改成 re-export，所以原本 import 它的地方一行都不用改。
2. mesh.faceTriangles() 當全專案唯一的三角化入口：
   三角形／四邊形／凸多邊形 -> 扇形（O(n)，而且跟以前逐字相同）；
   非凸 -> 投影到面的平面 -> 耳切（O(n²)，但很少走到）。
   ⚠ 耳切失敗就退回扇形，不要回傳空的 —— 回空的話那個面會整片消失，
   而使用者會以為模型壞了（坑第 11 條）。
3. 8 個出口全部改用它。⛔ 註解明寫「不要再自己寫 for (let i = 2; ...)」。
