【觸控改造】組裝系統結構說明表（+264 行）

- 3D 視角：抽出 orbitBegin/Move/End/Zoom/PanBy
  滑鼠維持左鍵轉、右鍵平移、滾輪縮放；觸控加單指轉、雙指捏合縮放與平移
- 側欄分隔線：抽出 grabStart/Move/End，滑鼠與觸控各接一組入口
- 說明表預覽：新增縮放狀態，雙指捏合以手指中心為基準（已驗算按住的點不位移）、
  單指拖曳平移、右下角 −／⤢／＋ 按鈕
- CSS 以 @media (pointer:coarse) 與 @media (max-width:1100px) 隔離，
  1100px 以上桌機版面完全不變

修正：插入 CSS 時誤刪 @media print 開頭，導致列印規則全域生效、
側欄與工具列全被隱藏。已加入 CSS 結構檢查（大括號配對、media query 閉合、
破壞性規則是否確實包在 media query 內）避免重演。
