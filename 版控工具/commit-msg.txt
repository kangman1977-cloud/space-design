【三、順手升級四處成第一手】

  1. 限制性溶解  ✅ → ✅ 半
     Blender 有 Max Angle（可調的夾角門檻，「共面 = 0°，⚠ 不是 180°」）
     ＋ All Boundaries ＋ Delimit 五個開關（Normal/Material/Seam/Sharp/UVs）。
     我們是把門檻寫死在 MERGE_FLAT_TOL_CM（1 微米）＝ Max Angle 固定 0 的特例。
     ⭐ Delimit 的 Seam 我們其實有對應物（CUT／hard 邊）。

  2. 刪除  ✅ 面 → ✅ 1/5
     官方是五種不是三種：Vertices / Edges / Faces /
     Only Edges & Faces / Only Faces。
     後兩種跟前三種的差別只有一件事：孤立的點要不要留下來。
     ⚠ 孤點正好是我們踩過坑的地方（四個「拆掉重建」的工具全會產生孤點）。
     ⭐ Blender 把「留不留孤點」交給使用者選，我們一律清掉。

  3. 由選取的點建面（F）
     🔴 F 是一顆鍵、兩種行為：「F 平常是建面，但在既有的面上執行時，
     它改成溶解那些面」（官方原文）。
     ⭐ 所以 F（建面）與溶解面在 Blender 裡是同一顆鍵，
       而我們把它們當成兩個獨立項目在排順序。
     ⚠ ⛔ 這不表示我們要跟著合成一顆（那違反「功能之間的定位不可以
       互相模糊」），但排順序時要知道它們是一組的。

  4. 🔴 新增一列：塌陷邊與面（Collapse Edges & Faces）
     整張表原本漏了這一支。官方特別點出它跟 Dissolve 的差別：
     「Unlike the Dissolve operators, this operator doesn't create n-gons」，
     而且它會新增頂點，不是只刪。
     ⚠ 對我們的意義：它是唯一一個「簡化網格但不產生 n 邊形」的路 ——
       而 n 邊形正是我們被「圖要能切」擋住的地方。⏳ 需求沒調查過。
