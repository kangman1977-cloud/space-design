加上搜尋引擎排除，避免被 Google 等收錄

倉庫是公開的（免費帳號的 GitHub Pages 必須公開），主要門檻是「要知道網址」。
但 GitHub Pages 的頁面仍有機會被搜尋引擎爬到，加兩層防護降低被偶然找到的機率。

【robots.txt】新增
  User-agent: *
  Disallow: /
告訴所有搜尋引擎不要索引這個網站。

【三個網頁的 head】各加一行
  <meta name="robots" content="noindex, nofollow">
即使 robots.txt 被忽略，頁面本身也標明不要收錄。

不影響任何功能：知道網址的人照常開啟使用，只是不會出現在搜尋結果。

擋不掉的部分（已向使用者說明）：
GitHub 站內搜尋仍可能翻到這個倉庫，那只能靠改成 Private 解決，
但免費帳號的 Pages 需要公開，改 Private 會讓網址失效。

檢查：三個網頁的 CSS 大括號平衡、JS 語法通過，noindex 標籤皆已加入。
