【kang 實測抓到的：「一個邊執行一次導角就會出現奇怪的形狀」】

🔴 病因不是「一次導幾條」，是偏移的方向算錯。
   只有一條邊被導時，旁邊那個面的角要「沿著沒被導的那條邊滑」，
   才會留在鄰居的平面上（那條邊正是兩個面的交線）。
   原本寫成「垂直於被導的邊偏移 w」。

⚠ 方塊把這個錯誤藏起來了：方塊的兩條邊互相垂直，
  「垂直於 A 偏移 w」跟「沿 B 滑 w」剛好是同一點 ——
  所以一次全導、或第一刀，看起來都完全正常。

症狀：吸收它的那個面變成非平面，三角化之後畫面上出現奇怪的形狀。
  修之前 一條一條導三次：非平面 0 → 1 → 2
  修之後                非平面 0 → 0 → 0

換算：沿 B 滑 t，離 A 的垂直距離是 t·sin(夾角)，所以 t = w/sin，
上限 5 倍（shell() 的老規矩）。

⭐ 修完掉出一個更強的性質：一條一條導三次 ＝ 一次導三條
   （體積 106270.833333、面數、χ 完全相同）。順序無關正是這個 bug
   壞掉時第一個會破的性質，已釘成測試。
   ⚠ 頂點數可以不同（14 vs 12）—— 一條一條會留下多餘但無害的點。
     所以測試驗幾何，不驗頂點數（第一版拿頂點數比，把正確結果報成失敗）。

【🔴 順帶推翻一句被當成事實的話：「我們的頂點全是 3 價」】

它寫在第 9.8 節、11.1 節、日誌、規格檔、程式註解裡，
而導角的角落規則就建在它上面。實測：

  方塊、32 段圓柱   全部 3 價           ✅
  圓錐 seg12        {3:10, 4:2, 5:2, 6:2} ❌

角落規則是「每個面都被導到才補」，只對 3 價成立 ——
3 價時那個沒被導到的面會同時吸收兩邊的代表點，自己把縫補起來；
4 價以上兩個吸收面各自只拿到一邊，中間留一個三角形的洞
（實測圓錐導一條邊：χ 1、邊界半邊 3 條）。

⚠ 通用的角落規則試了三次都沒解出來，照 kang 的規則
  「連續失敗超過 3 次就停下回報」停下來了。三次分別是：
    1. 每個面在頂點出一個代表點        → 只導一部分時不封閉（χ −2）
    2. 依「繞一圈剩幾個相異點」決定     → 方塊多出假角落面；圓錐 χ −35
    3. 把只用到一次的邊串成迴圈補       → 方塊的角落案例反而破了（χ 1）

→ 現在的處理：擋下來並講清楚原因。做出一個破洞的網格比擋下來糟得多
  （坑第 11 條）。三次分別錯在哪，寫進 外部參考-Blender編輯.md 第 11.7 節，
  並註明「下一個人要解這題之前先看完那三次 —— 每次都通過了一部分案例，
  所以『看起來對』不是證據」。

✅ 不受影響：方塊、圓柱、圓角方塊（非直角，一條一條導三次全程 χ2 封閉
   無非平面）、以及頂點被全部導到的情形（12 條全導照樣可以）。
