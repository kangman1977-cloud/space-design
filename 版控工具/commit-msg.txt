【⑤ 🔴🔴 一個會安靜失效的地雷（抓到了）】

  hidden 屬性的效果 display:none 是【瀏覽器預設樣式】，
  而 .grp { display: flex } 是【作者樣式】—— 作者的贏。
  ⇒ ⛔ 沒有 `.grp[hidden] { display:none }`，整組收起來【完全不生效】，
    而且不會報錯、看起來就像程式沒跑到。
  ⭐ 這個專案已經踩過一次：.uwWin[hidden] 那一行就是為了同一件事存在的。

【⑥ ⚠ 而我補那一行時把 .grp 改壞了 —— 大括號還是平衡的】

  padding／border 掉進了 .grp[hidden] 裡，而 { 134 } 134 【平衡】。
  🔴 這正是 2026-08-20 @media print 那個坑：【平衡⛔ 不代表對】。
  ⇒ 改用「逐條規則印出 選擇器 → 宣告」來驗，⛔ 不是只數括號。

【⑦ 整組空了自動收起來 —— ⛔ 不列名單】
