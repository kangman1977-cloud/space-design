空間平面規劃器：加入觸控支援（事件入口分開、動作邏輯共用）

沿用說明表驗證過的原則：桌機 mouse 路徑行為不變，觸控是另外新增的入口，
兩者最後呼叫同一組動作函式。

【2D 畫布】抽出 canvasBegin / canvasMove / canvasEnd / canvasZoomAt / canvasPanBy
canvasBegin(sx,sy,opt) 的 opt：pan 強制平移、shift 加選、marquee 強制框選

- 滑鼠：中鍵/右鍵/空白鍵平移、左鍵拖曳、Shift 加選、滾輪縮放（與原本相同）
- 觸控：
  - 單指按在物件或把手上 = 移動 / 縮放 / 旋轉
  - 單指按在空白處       = 平移畫布
  - 空白處按住約 0.45 秒 = 轉為框選模式（跳出提示，移動超過 10px 則取消）
  - 雙指                 = 捏合縮放 + 同步平移

解決的衝突：桌機上「空白處拖曳」是框選，但在平板上那個手勢更該是平移。
改成長按才進框選，兩種需求都保留。

【3D】抽出 orb3Begin / orb3Move / orb3Zoom / orb3PanBy
滑鼠維持左鍵轉、右鍵平移、滾輪縮放；觸控加單指轉、雙指捏合縮放與平移。
第一人稱漫遊需要滑鼠鎖定，iPad 不支援，因此在 pointer:coarse 隱藏該按鈕。

【側欄分隔線】抽出 grabStart / grabMove / grabEnd，滑鼠與觸控各接一組入口

【版面】
- @media (pointer:coarse) 加大按鈕、物件庫項目、分隔線；把手 HS 由 7px 改 12px、
  命中寬容值 HGRAB 由 2px 改 14px（手指才點得到四角把手）
- @media (max-width:1100px) 側欄改抽屜（含遮罩、點擊關閉），1100px 以上版面不變
- touch-action 只設在 2D/3D 畫布與分隔線，其餘保留瀏覽器預設
- 新增 #toast 短暫提示，用於告知已進入框選模式

【檢查】CSS 大括號平衡、兩個 media query 皆正確閉合、
display:none!important 兩處都確實包在 media query 內、
JS 語法通過、onclick 函式與 DOM 元素皆存在。
