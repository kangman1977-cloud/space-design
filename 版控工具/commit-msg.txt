【協作規則新增「這個專案踩過的坑」】
把七個實際發生過的錯誤寫下來，每個都附原因與對策：
1. 沙箱跑 git status 也會鎖住 repo（唯讀指令一樣建 index.lock）
2. CSS 插入時誤刪 @media print 開頭（語法檢查抓不到，只有 diff 抓得到）
3. .bat 含中文會亂碼、LF 換行會讓 goto 失效
4. 轉檔腳本把檔案寫成 0 bytes（wb 先清空，encode 才拋例外）
5. flex 項目預設會被壓縮，導致工具列文字直向折行
6. 小物件的縮放把手會蓋住物件本身，命中判斷與繪製必須用同一個函式
7. iPad 全螢幕時內容跑到狀態列底下
