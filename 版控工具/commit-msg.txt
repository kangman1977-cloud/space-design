版控工具：新增平板測試伺服器，並補上 stale lock 偵測

【新增】平板測試-啟動伺服器.bat
把專案資料夾分享到內網，讓 iPad / Android 平板用瀏覽器開啟測試。
唯讀：只提供檔案，不寫入、不刪除、不碰 .git。關掉視窗即結束。
自動偵測 py / python / node，都沒有就提示安裝方式並退出。
會列出本機 IPv4 網址供平板輸入。

【修正】1-看差異.bat / 2-存檔.bat 加入 .git\index.lock 偵測
偵測到 stale lock 就停下並印出清除指令，不會像先前那樣執行到一半 fatal。

起因：AI 在沙箱執行 git status / check-ignore / ls-files 做檢查，
這些唯讀指令一樣會建立 index.lock，而沙箱沒有刪除權限，
導致 2-存檔.bat 首次執行時 commit 失敗。

規則已改寫為沒有解釋空間的版本，寫進 版控工具\README.md 與 PROJECT_LOG.md：
沙箱一律不執行任何 git 指令，包含唯讀的 git status / git diff / git ls-files；
只能用 Read / grep 讀檔案內容。
