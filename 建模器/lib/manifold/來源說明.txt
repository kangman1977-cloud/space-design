為什麼選它
---------------------------------------------------------------
原本規劃用 three-bvh-csg。實測同一題（方塊 60x45x40 挖 ⌀20 貫孔）：

                        three-bvh-csg      Manifold
  耗時                      40 ms            0 ms
  三角形                     376             144
  尤拉數（應為 0）           -113  X            0  OK
  網格封閉                    否              是
  結構問題                  244 項            0 項
  角虧總和（應為 0）           --         0.000000  OK

three-bvh-csg 的輸出有 506 條邊沒有鄰居 —— 畫面看不出來，
但第 3 期展開引擎第一件事就是問「這條邊隔壁是哪個面」，
接不起來的網格會讓展開直接失效。

Manifold 的設計目標就是「保證輸出是封閉可接的網格」，
使用者包含 OpenSCAD、Blender、Godot Engine、BRL-CAD、
Babylon.js、trimesh 等。


日後要更新版本
---------------------------------------------------------------
  npm pack manifold-3d@<版本>
  解開後把 manifold.js 與 manifold.wasm 換掉即可。
  換完務必跑一次 建模器/tests/run.mjs 對答案。

  透過我們自己的介面呼叫。換庫只要改那一個檔，
  運算樹格式、面板、Undo、存讀檔都不用動。
