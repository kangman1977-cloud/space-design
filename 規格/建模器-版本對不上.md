# 建模器：畫面跟程式的版本對不上時，⛔ 整個停住

> 起點：2026-10-14 AI 線上先驗曲線刀具第四步時撞到 —— 重新載入拿到**舊的主頁面 ＋ 新的程式**，
> 新程式要接「切穿」那顆新按鈕，舊頁面上沒有它 ⇒ `main.js` 第 706 行丟錯 ⇒ 後面的程式全部沒跑、整個建模器按什麼都沒反應。
> kang 2026-10-14 從待辦裡選「找不到按鈕時不要整個停住」。

## 為什麼會一新一舊

主頁面（網址是資料夾 `建模器/`）跟程式檔（`js/…`）是瀏覽器**各自暫存**的。剛上傳的幾分鐘內，可能一個換新了、一個還是舊的。
每次加新按鈕都有這個風險（以前沒撞到只是運氣）。按 F5 會讓瀏覽器重新確認主頁面，就好了。

## 做法

- `main.js` 的 `$(id)`：找不到 ⇒ 回一個**沒放進畫面的替身**（同一個 id 永遠回同一個），寫 onclick、hidden、value 都不會出錯
- 第一個找不到的 ⇒ 等這一輪跑完，在畫面最上面掛一條提示：
  「畫面跟程式的版本對不上（多半是剛有新版、瀏覽器還留著舊的畫面）—— 按 F5 重新整理就好。在那之前有 N 顆按鈕或欄位不會出現。」
  點那一條 ＝ 重新整理；主控台印出缺的是哪幾個 id
- 提示條用程式做出來（⛔ 寫在 `index.html` —— 舊頁面上不會有它）
- ⚠ 這⛔ 是拿來掩蓋打錯字的：替身一出現就有提示
