### 規則

| | |
|---|---|
| **每個物件在一層** | 新文件、舊檔都只有一層「預設」；舊檔的物件全部放「預設」 |
| **目前這一層** | 清單上標「目前」的那一層；點別一層的名字就換過去。**全新做的**（新增形狀、鋼筆、匯入 SVG、匯入 3D）放這一層；目前這一層⛔ 能關、鎖、刪 |
| **從舊物件變來的** | 複製、布林、分割、陣列／鏡射、打散、切穿／挖洞、3D 列印切塊（含插銷）、分離、切成實心 ⇒ 跟原本那個同一層（顏色跟不跟圖層也照它）|
| **在哪** | 右側面板最上面兩個分頁「工具與屬性｜圖層」；選「圖層」⇒ 面板只剩這一頁。選哪一頁記住 |
| **清單** | 每一層一列：▸ 展開、👁 關／開、🔒 鎖／解、顏色、名字、幾個物件、✕ 刪（目前這一層寫「目前」、⛔ ✕）；展開後每個物件一列：👁（物件自己藏起來）、🔒（物件自己鎖住）、名字（點 ＝ 選它，Shift 加選）|
| **底下一排** | ＋新圖層（名字「圖層 N」、加在最下面、換成目前這一層）、改名（目前這一層，打完按 Enter）、移到「目前這一層」（選到的）、這一層全部用圖層顏色 |
| **刪一層** | 沒東西 ⇒ 直接刪；有東西 ⇒ 列下面跳出「一起刪掉／移到『預設』／取消」（⛔ 用瀏覽器的確認框）；最後一層⛔ 能刪 |
| **圖層關掉** | 那一層的物件看不到、點不到、沒選東西出圖不算 —— 跟物件「藏起來」效果一樣但**分開記**：「全部顯示」只拿回物件自己藏的；狀態列多寫「關掉的圖層裡 N」，全部顯示後還有就提醒 |
| **圖層鎖住** | 那一層的物件半透明、點不到（跟物件「鎖住」一樣，分開記）|
| **顏色** | 物件面板「顏色用：自己的／跟圖層」，預設自己的（畫面⛔ 變）；跟圖層 ⇒ 用那一層的顏色（清單上改）。匯出都⛔ 用顏色 |
| **物件面板** | 多「顏色用」與「圖層」兩列（多選一起改）；圖層換了就移過去 |
| **拉出來** | 清單那一頁的「拉出來 ↗」⇒ 浮動視窗（一開始在 3D 畫面右上角、XYZ 小方向標下面）；「放回面板 ↘」回來（面板收著會一起打開、切到「圖層」）。⚠ 跟「工具」不一樣：面板收起來⛔ 自動浮 —— 清單一直蓋在畫面上會擋模型。有沒有拉出來、放哪、收不收記住 |
| **復原、存檔** | 清單上每一個動作記一步（換目前這一層⛔ 記，只存檔）；圖層表、目前這一層、物件在哪一層、顏色跟不跟圖層都存進檔 |
| **新建** | 回到只有「預設」一層（「刪掉所有物件」⛔ 動圖層）|
| **先⛔ 做（kang ⑥）** | 子圖層、拖拉排序、匯出寫圖層名 |
