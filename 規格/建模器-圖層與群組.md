## 第一批（2026-10-27 做）

### 規則

| | |
|---|---|
| **在哪** | 右側「工具」區最前面一組「顯示」（面板收起來時在上方工具列最後面，跟其他工具組一樣）|
| **藏起來** | 選了東西才出現；按了 ⇒ 選到的看不到、點不到、框不到、Ctrl+A 選不到；入鏡不算它；鋼筆⛔ 吸它的外框 |
| **鎖住** | 選了東西才出現；按了 ⇒ 選到的變半透明（看得到、當參考），點不到、框不到、Ctrl+A 選不到；出圖照算（看得到的都算）|
| **只看選到的** | 選了東西、或正開著才出現；按了 ⇒ 其他看得到的先藏起來、按鈕亮著；再按一次 ⇒ **只放回它藏的**，自己按「藏起來」的照舊藏著（Rhino 的 Isolate／Unisolate）|
| **全部顯示（N）、全部解鎖（N）** | 有藏的／鎖的才出現，括號寫幾個 |
| **一直提醒** | 左下狀態列：有藏、有鎖就一直寫「藏起來 N　鎖住 N」（琥珀色）|
| **出圖、檢查** | 沒選東西時只算看得到的（STL／3MF、OBJ、展開圖、剖面分切、干涉檢查、齒輪檢查），視窗寫「（有 N 個藏起來的沒算）」；干涉檢查查不了（只剩一個）時也講。有選東西 ⇒ 照選的、⛔ 講 |
| **復原** | 每按一次記一步，Ctrl+Z 退得回來 |
| **存檔** | 藏、鎖、「只看選到的」藏的都存進檔（重新整理、存檔讀檔都還在）；沒藏沒鎖的檔一個字都不多；舊檔照常打得開 |
| **AI 幫手** | `AI.看()` 照樣列藏起來、鎖住的物件，加「藏起來」「鎖住」標記 |

⚠ **跟樣板不一樣的一處**：樣板把「全部顯示、全部解鎖」畫在上方「檢視」那組；照 ⑤-2 的規則（上方前 7 組一直都在、寬度不變；會出現、消失的放後面）改放「顯示」那一組。

### 怎麼做到的

- `core/io.js`：`ModelObject` 加 `hidden`、`locked`、`isoHidden`（建構子、`toJSON()` 有才存、`fromJSON()` 三處都加 —— 漏一處存檔與復原都會丟）；`Doc.shown()`、`hiddenCount`、`lockedCount`、`hiddenNote(picked)`；`setShown(doc, how, picked)` 純改資料回報改了幾個；`isIsolated(doc)`。
- `view/scene.js`：`_updateNode()` 設 `node.visible = !obj.hidden`、記 `userData.locked`；`_applyGhost()` 鎖住的半透明 `LOCKED_OPACITY` 0.4（編輯路徑那一個照舊 0.28）；`pickables` 濾掉藏、鎖的（⚠ three.js 的點選⛔ 看 `visible`）；`frameAll()` 跳過看不到的。
- `view/select.js`：`set()` 與 `revalidate()` 走 `_canPick()`（藏、鎖的選不進來 —— 點、框、全選、AI 選、復原回來一處擋全部）；拉框先濾掉；鋼筆吸外框跳過藏起來的。
- `main.js`：`showOp()`（改資料 → 重畫 → 選取重新過濾 → 記一步）；`updateBar()` 管五顆的出現與括號、狀態列 `#sShow`；干涉檢查用 `doc.shown()`、講幾個沒算。
- `ui/exportPanel.js`、`objPanel.js`、`unfoldPanel.js`、`slicePanel.js`：「沒選就全部」改 `doc.shown()`、摘要加 `hiddenNote()`；`toolbar.js` 齒輪檢查用 `doc.shown()`。
- `ai/assist.js`：`objectInfo()` 加標記；功能地圖 `catalogInfo.js` 加「工具：顯示」那一組與三顆的前提。

### ⏳ 實測（kang）

1. 按「新建」→「加入」方塊（60 × 45 × 40）→ 形狀選「圓柱」按「加入」（放在旁邊、自動選起來）⇒ 右側「工具」最上面多一組「顯示」：**藏起來、鎖住、只看選到的**。
2. 按「藏起來」⇒ 圓柱不見；左下狀態列多一行「藏起來 1」；「顯示」那一組變成「全部顯示（1）」。在原本圓柱的位置點、拉框、按 Ctrl+A ⇒ 都選不到它（Ctrl+A 只選到方塊）。
3. 選方塊、按「鎖住」⇒ 方塊變半透明；點它、框它都選不到；狀態列「藏起來 1　鎖住 1」；多「全部解鎖（1）」。
4. 什麼都不選、按「3D 列印」⇒ 上面那行最後寫「（有 1 個藏起來的沒算）」，物件數是 1（鎖住的方塊照算）。
5. 按 F5 重新整理 ⇒ 圓柱還是藏著、方塊還是鎖著。
6. 按「全部解鎖」⇒ 方塊回來（不透明、點得到）；按 Ctrl+Z ⇒ 又鎖回去；Ctrl+Y ⇒ 再解開。
7. 再加一個方塊、選它、按「只看選到的」⇒ 其他看得到的方塊藏起來、按鈕亮著；再按一次 ⇒ 那個方塊回來，**圓柱照舊藏著**（它是你自己藏的）。
8. 按「全部顯示（1）」⇒ 全部回來；「顯示」那一組與狀態列那一行收起來。
