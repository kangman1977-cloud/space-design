## 第二步：省道打版的攤平 ＋ 展開圖視窗（2026-10-12 結案）

### 2.1 沙箱先做算法（⛔ 網頁還沒動）

**目標**（`外部參考-打版.md` 第 4 節定案）：**縫邊長度 ＝ 3D 真值（硬規定）**，變形只准擠到片的中間。

**做法**（彈簧法 ＝ 業界的能量最小化那一類；每個面的邊與對角線當彈簧，拉回原長）：

1. 剛體攤平當起點（模式一同一套）
2. 整片一起拉（縫邊加重）
3. **交替**：中間拉一次 → 縫邊拉回原長好幾次，反覆
4. 最後只拉縫邊，直到縫邊誤差 < 0.0000001%

⚠ **試過但比較差的**：「縫邊先拉準、再固定縫邊只動中間」（三段）—— 縫邊準了，但中間被逼到極端（球 4 片不開口拉 80%）。
**交替**在同樣條件下是 22%。

**拓撲上非剪不可的切線**（例：圓環切成一段一段，每段是一個「環」，不剪一刀攤不開）：
模式一那套程式自己剪的邊，**一直修掉「停在片中間」的那一頭**（端點不在邊界、只接一條的就拿掉）——
剩下的就是**只為了攤開才剪**的那幾條；**⛔ 不再為了「鼓」而剪**（鼓的交給材料伸縮）。
→ 球、半球一條都不剪；圓環每段剪一條（8 條邊）。

**量測**（`segW×segH`；縫 ＝ 經線每 N 條切一條；開口 ＝ 其餘經線從兩極往赤道切 k 格，共 segH/2 格）：

| 情境 | 片 | 程式加 | 最多拉 | 最多壓 | 縫邊最多差 | 翻面 |
|---|---|---|---|---|---|---|
| 球 12×16、6 片、不開口 | 6 | 0 | 5.2% | 12.0% | **0.00%** | 0 |
| 球 12×16、4 片、不開口 | 4 | 0 | 21.7% | 30.2% | **0.00%** | 0 |
| 球 12×16、4 片、開口 5 格 | 4 | 0 | 9.0% | 11.1% | **0.00%** | 0 |
| 球 12×16、4 片、開口 7 格 | 4 | 0 | 1.5% | 1.9% | **0.00%** | 0 |
| 預設球 32×16、8 片、開口 6 格 | 8 | 0 | 4.8% | 3.2% | **0.00%** | 0 |
| 預設球 32×16、4 片、開口 7 格 | 4 | 0 | 1.1% | 1.7% | **0.00%** | 0 |
| 半球 16×8、底蓋切開、不開口 | 2 | 0 | 52% | 57% | **0.00%** | **50** |
| 半球 16×8、底蓋切開、每條經線從邊緣開口到 6 成高 | 2 | 0 | 37% | 21% | **0.00%** | **1** |
| 圓環（預設）切 4 段 | 4 | 8×4 | 27% | 31% | **0.00%** | 0 |

- 對照樣板（縫邊加重、⛔ 硬規定）：縫邊會差 0.2%～6.8%；**硬規定之後一律 0.00%**，中間的拉／壓多一點點，是正常的代價。
- **收斂**：交替 1000 輪 vs 16000 輪，數字差不到 0.05% ⇒ 正式版「數字不動了就停」，預設球 8 片約 0.3 秒。
- 🔴 **半球那兩列是真的做不出來**（⛔ 算法的錯）：開口停在 6 成高，上面那頂「帽子」還是一個很鼓的球冠；
  不開口更是整個半球要攤成平的。⇒ **翻面（攤平後有地方疊在一起）一定要講出來**，跟模式一的「重疊」同一則警告。

### 2.2 ✅ kang 2026-10-12「依照你的建議處理」（樣板裡沒碰到的四件）

1. **折線**：布、皮不會在網格的稜線上折。省道打版的圖**⛔ 畫折線、⛔ 標折彎角度**（球一片會有幾百條）—— 只畫切割線、開口、上色。
2. **上色放哪裡**：畫面、列印上色；**SVG／DXF 只放線**（切割線、開口）＋ 每片的三個數字文字 —— 送去切的檔⛔ 帶色塊。
3. **材料**：省道打版**⛔ 管「折不折得動」**（布哪裡都彎得了），只照你標的切線分片；材料只用在「縫份」那一行。
4. **程式為了攤開才剪的那一刀**（圓環那種）：跟模式一一樣畫**橘色** ＋ 卡片寫條數。

### 2.3 接進建模器（2026-10-12 結案）

| | 在哪 | 做什麼 |
|---|---|---|
| 展開方式 | `unfold/flatten.js` `unfoldMesh(…, { mode: 'dart' })` | 幾何核心看到「什麼都折得動」的規則（⛔ 管材料）；`rule.validate()` 照舊用原本的 |
| 只剪非剪不可的 | `pruneToTopology()` | 模式一那批程式自己剪的邊，用佇列一直修掉「停在片中間」的那一頭 |
| 攤平 | `relaxDart()` | 一圈一圈往外擺當起點 → 整片拉 → 交替（中間一次、縫邊六次）→ 只拉縫邊到誤差 < 十億分之一；收斂看「扣掉平移與轉動後形狀變多少」< 片大小的百萬分之五 |
| 一片的資料 | `buildPiece()` | `piece.strain`（每面拉伸、最多拉／壓、縫邊差、翻面數、是否算完、攤平後面積）、`piece.dartCut`（哪幾段是開口、每點是哪個頂點）；⛔ 折線、⛔ 圓弧修正；面積改成攤平後的 |
| 警告 | `unfoldMesh()` | 有面翻過來 ⇒「這片就算能拉也做不出來…多開幾道開口或多分幾片」；算到上限還沒停 ⇒ 講出來 |
| 每段畫什麼 | `out/sheet.js` `outlineSegments()` | 展開圖與 DXF 共用：一般／程式加的（橘）／開口剪掉（紫實線）／開口只畫縫線（紫虛線 ＋ 口子一條切割線）|
| 上色 | `drawProgram()` | `opt.strainFill` 才畫（畫面、列印）；存 SVG／DXF 傳 `strainFill: false` |
| 卡片 | `titleLines()` | 三個數字；開口 N 道（畫法）；填了上限 ⇒ 超過紅字／以內；面積「（攤平後）」|
| DXF | `out/dxf.js` | 新圖層 **SEW**（只畫縫線的開口縫線，⛔ 是切割線）；剪掉的開口在 CUT；標題帶 `STRETCH … SHRINK … SEAM …`（R12 只收英數）|
| 視窗 | `ui/unfoldPanel.js` | 「展開方式」一排；選省道打版才出現「這個材料最多能拉 __ %」「開口畫成」。展開方式這一頁開著的期間記得、⛔ 存瀏覽器（下次從精確分片開始）；上限與畫法記在瀏覽器 |

kang 2026-10-12（用**圓環**、材料**珍珠板／發泡板**做省道打版）：「當展開圖完成並要匯出時..可以有一個開/關可以讓 DXF 與 SVG 能夠出現『折線』的功能嗎?」
附 Illustrator 截圖，紅框裡自己畫了一條示意線：「這裡應該要有一條折線，但現在沒有」。
⇒ 第二步定的「省道打版⛔ 畫折線」是照**布**想的；**板材做省道打版要知道每一格在哪裡折**。

| kang 定的（「依照你的建議」）| 內容 |
|---|---|
| 開關 | 展開圖視窗「省道打版」那一排「**畫折線**」，**預設關**，記在瀏覽器裡 |
| 畫在哪 | 打勾時**畫面、列印、SVG、DXF 都畫**（「畫面看到什麼，存出去就是什麼」）；右側即時預覽也跟著 |
| 畫什麼 | **只畫線、不標角度**（片有拉伸，位置是參考）；卡片多一行「折線 N 道（只畫線、不標角度…）」|
| DXF | **FOLD 層**（跟精確分片的折線同一層、同一種紅色點劃線）|

做法：`buildPiece()` 照樣找折線（`collectFolds()`），省道打版時放進 `piece.dartFolds`（`folds` 照舊是空的 ⇒ ⛔ 折彎標註、⛔ 圓弧修正）；
點是 `pt2` 裡的同一個物件，所以是**拉過、擺正之後**的位置。

⚠ AI 自己做的時候寫錯一次：卡片寫成「只畫線、⛔ 標角度」—— 把文件裡的 ⛔ 符號寫進畫面，少了「不」。看圖時發現，改成「不標角度」。

#### ⏳ 給 kang 的實測清單（畫折線，2026-10-12）

前置：線上版，**先按右側「抓最新版」**。照你截圖那樣：圓環 → 轉成可編輯網格 → 分片切幾段 → 展開圖 → 省道打版。

| # | 怎麼做 | 應該看到 |
|---|---|---|
| 1 | 看「省道打版」那一排 | 最後多一個「**畫折線**」，沒打勾；圖上沒有折線（跟現在一樣）|
| 2 | 打勾 | 每片的格子之間出現**紅色點劃線**；卡片多一行「折線 N 道（只畫線、不標角度…）」|
| 3 | 存 SVG → Illustrator | 有折線（紅色點劃線）—— 就是你截圖紅框那種位置 |
| 4 | 存 DXF → Illustrator | 折線在 **FOLD** 層；切割線照舊在 CUT（程式加的在 CUT_AUTO）|
| 5 | 排版開著存 SVG／DXF | 每張板上的片也有折線 |
| 6 | 關掉展開圖 → 看右側即時預覽 | 預覽上也有折線；取消勾 ⇒ 預覽也沒有 |
| 7 | 重新整理網頁再打開 | 「畫折線」還是上次的狀態 |
| 8 | 改回「精確分片」| 圖跟以前一模一樣（精確分片本來就有折線與角度）|
