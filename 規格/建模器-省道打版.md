## 樣板跟正式版差在哪（⚠ 動工時照這張，⛔ 照樣板抄）

| | 樣板 | 正式版 |
|---|---|---|
| 模型 | 寫死的一顆球 | 建模器裡任何「轉成可編輯網格」的物件 |

| 攤平 | 彈簧法、縫邊加重 —— **縫邊長度實測會差好幾 %** | 縫邊長度**當硬規定**（`外部參考-打版.md` 附錄：technet 用 Lagrange 硬約束、ExactFlat「no seam stretch」）|
| 出圖 | 畫在畫布上 | 走現有的 `drawProgram()` → 畫面／SVG／DXF／排版同一份 |

## 第一步：「標一段」＋ 3D 上開口另一個顏色（2026-10-12 結案）

| | 在哪 | 做什麼 |
|---|---|---|
| 標一段 | `core/selectops.js` `seamSpanEdges()` | `edgeLoop()` 從起點往兩邊走，終點落在哪一邊就取那一段；繞一圈的線取短的那段；⛔ 同一條線 ⇒ `null` |
| | `main.js` `seamPick()` | 第一下＝起點（黃線，`view.setSeamSpanStart()`），第二下＝終點，照起點是不是切線整段切換、一步 Undo。再點起點＝取消；換點法、離開分片、Undo 都清掉起點（`dropSeamSpan()`）|
| | `ui/toolbar.js` | 「點一條稜線時」多一項「標一段（先點起點、再點終點）」；有開口時多一行「其中 N 條是開口」 |
| 縫／開口 | `unfold/seam.js` `seamKinds()` | 只看使用者標的切線：切開後兩側還是同一片 ＝ 開口 |
| | `view/scene.js` | 開口另一條線畫（`DART_COLOR`），縫照舊橘色 |

✅ **開口的顏色：黃綠**（kang 2026-10-12「依照你建議」）。
kang 在樣板上看的是紫色，但 3D 畫面上紫色已經是「非流形邊」（`setNonManifoldPreview()`，「紫＝這裡黏在一起了」），
而接縫線一直都顯示著 —— 兩個可能同時出現 ⇒ 換成 3D 上沒用過的黃綠（`scene.js` 的 `DART_COLOR`）。
