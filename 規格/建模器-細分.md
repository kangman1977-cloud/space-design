## 怎麼切（`edit.js` `subdivideFaces()`）

選到的每一個面（⚠ 一個面 ＝ 共面區域，先擴成區域裡的每一片），🔴 **照它真正的「角」數**（跟兩旁連成一直線的點⛔ 不算角）：

| 角數 | 切法 | n 等分之後 |
|---|---|---|
| 3 | 每條邊 n 等分，裡面照格子連 | n² 個三角形 |
| 4（凸的）| 每條邊 n 等分，裡面照格子連（雙線性）| n² 個四邊形 |
| 5 以上（凸的）| 中心加一點、每個角一條輻條切成扇形，每一片再照 3 角的規則切 | 角數 × n² 個三角形 |
| **凹的** | ⛔ 不切，只在每條邊的 k/n 上加點 | 1 個面（多了點）|

🔴 **為什麼照「角」⛔ 照「點」**（2026-10-14 AI 線上先驗抓到的，kang「先修再實測」）：
② 讓旁邊的面邊上多出點。照點數算，方塊頂面細分過兩次之後，前面是「9 邊形」⇒ 再細分它被切成 **324 片細長的扇形**，⛔ 不是 6×6 格子 ——
而「先細分一塊、再往旁邊擴大」正是安全帽那種做法一定會走的路。

- 一條「邊」＝ 角到角；它在 k/n 的位置要有一個點：**附近原本就有點（一格的 1/10 以內）就直接用那個點**，否則插一個新點
- 邊上原本多出來、⛔ 落在 k/n 的點，**照樣接在那一格上**（那一格是多一兩個點的多邊形，形狀不變）

- **選取旁邊的面**：共用的邊上被切出來的點插進它的迴圈 ⇒ 變成多一點的多邊形，形狀不變（跟「邊上加點」同一件事，⛔ 不另寫：共用 `rebuildWithInserts()`）
- **既有的點保持原索引、新點往後加**（標記的索引配對才對得上）
- **原本的邊被切成幾段，每一段都繼承原本那條邊的標記**（分片、折線、平滑…整包搬）
- 🔴 **新長出來的線全部標 `hard`** —— 它們跟原本的面共面，⛔ 不標的話畫面上看不見、點不到、細分出來的小面選不起來（內縮那一輪同一條）
- 一段比 `PLANAR_TOL_CM`（0.1 mm）還短就擋下來（跟「邊上加點」同一條）

```
選面（可以好幾個）→ 等分欄填幾等分 → 按「細分」

```
