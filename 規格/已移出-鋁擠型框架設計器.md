**原主檔案**：`鋁擠型框架設計器.html`（獨立網頁，單位 **mm**）

## 用途
用 40 系列鋁擠型搭工作桌架／料架／防護框，3D 即時預覽，自動產生切割料表與配件清單。

## 座標與資料模型
X＝長、Z＝深、Y＝高，原點在框架**底部中心**。

```
member = { id, prof:'4040', p1:[x,y,z], p2:[x,y,z], joint:'corner'|'butt', name }
```
桿件用起點／終點表示，長度自動算，因此斜撐也能做。

## 兩個獨立選項（重要，別混淆）
| 選項 | 影響 | 說明 |
|---|---|---|
| **框架接法** `post` / `beam` | **切料長度** | `post` 立柱通長＝H，橫梁扣兩端立柱寬；`beam` 橫梁通長＝L，立柱扣上下梁高 |
| **接合方式** `corner` / `butt` | **只影響配件** | 角件外掛 vs 端面內接。兩者桿件切料長度相同 |

驗證過的數字（1800×750×800、4040）：
- 柱通長 → 立柱 800×4、長梁 1720×4、短梁 670×4
- 梁通長 → 立柱 720×4、長梁 1800×4、短梁 670×4
- 換成 4080（斷面寬 80）→ 長梁 1640、短梁 590

## 型材資料（`PROF`）
4040 / 4040輕型 / 4080 / 40120 / 8080，各含斷面尺寸與 kg/m。
**kg/m 為市售概略值**，要精確請依供應商規格改 `PROF` 這個物件。

## 配件推算規則
桿件端點若落在另一支桿件的斷面範圍內（半寬＋3mm）即算一個**接點**，其餘為**外露端**。
- 角件外掛：每接點 N 個角件（預設 2，可調），每角件配 2 支 M8 螺栓 + 2 個 T 型螺帽
- 端面內接：每接點依斷面模組數配內接組（4040＝1、4080＝2、8080＝4）
- 外露端各 1 個封蓋；位於最低處的外露端另計調整腳杯

## 功能
- 4 個範本：箱型框架 / 工作桌架 / 多層料架（層數可設）/ 防護圍籬
- 3D：真 T 溝斷面（ExtrudeGeometry，可關成方管加速）、等角/前/側/俯視、陰影、外框尺寸標註
- 點選 3D 桿件即選取，右側可改型材、接合、起訖點、長度；可複製／刪除／加單支桿件
- 切割料表（含可調鋸切裕度）＋ 配件清單，可匯出 CSV
- JSON 存讀檔、PNG 截圖、localStorage 自動暫存（key: `alu_frame`、`alu_panels`）
