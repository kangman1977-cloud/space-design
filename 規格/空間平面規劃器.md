## 專案目的
網頁式的空間配置工具，讓非設計軟體使用者能在瀏覽器上自由擺放物件、
用真實尺寸預覽廠房／辦公室配置，並可切換 3D 檢視感受空間感。

## 確定狀態
- **主檔案**：`空間平面規劃器.html`（單一檔案，雙擊即可用瀏覽器開啟）
- **技術**：原生 JS + Canvas 2D；3D 使用 three.js r128（CDN 載入，需網路）
- **單位**：全部以 **cm** 為內部單位
- **座標**：2D 的 (x, y) → 3D 的 (x, z)；物件 `z` 欄位＝高度

## 已完成功能

### 2D 平面
- 物件庫點擊新增、自訂尺寸新增
- 拖曳移動、四角把手縮放、旋轉把手（Shift 鎖 15°）
- 網格吸附（5 / 10 / 25 / 50 / 100 cm 可切換）
- 框選多選、靠左／靠上對齊、水平／垂直均分
- 屬性面板可精確輸入 X / Y / 寬 / 深 / 高 / 角度 / 顏色 / 類型
- 量測工具（量走道寬度）、底圖比例校正工具
- Undo / Redo、JSON 存讀檔、PNG 匯出、localStorage 自動暫存

### 3D 預覽
- 環繞檢視（左鍵轉、右鍵平移、滾輪遠近）
- 第一人稱漫遊（點畫面鎖定滑鼠，WASD 移動、Shift 快走、Q/E 升降）
- 牆體碰撞（房間只擋牆、可走進室內；名稱以「門」開頭的物件不擋路；可勾「穿牆」關閉）
- 底圖可貼在地板上、外牆、名稱標籤、陰影，皆可開關

## 分層造型（tiers）
物件可由多層方塊堆疊，做出「上寬下窄」等造型（如工作桌桌面外伸、機台底座／機身／機頭）。

```
o.tiers = [ {name, w, h, z0, z1, dx, dy, color}, ... ]   // 沒有此欄位＝單一方塊
```
- `z0/z1`＝該層離地的下緣／上緣；`dx/dy`＝相對物件中心的水平偏移
- `o.w / o.h / o.z` 永遠是所有層的**外框**（由 `fitTiers()` 自動重算並重新置中）
- 改主面板的寬／深／高 ＝ 等比縮放所有層（`setObjSize()`），只在 change 時觸發避免逐字累積誤差
- 內建範本：`desk`(工作桌) / `machine`(機台) / `cabinet`(櫃體) / `platform`(平台)
- 只有 `kind==='solid'` 支援分層；改成房間或區域會清掉 tiers

## 從「組裝系統結構說明表」匯入（kind: system）
說明表按「⇪ 匯出給平面圖」產生交換 JSON，平面規劃器按「⇩ 匯入組裝系統」讀入。
**是加入現有平面圖，不會清空既有物件**；匯入後自動選取新物件，可直接拖曳定位。

交換格式：`{type:'assembly-system', v:1, unit:'cm', head, systems:[...]}`
每個 system 帶 `w/h/d`、`ps`、`postXs`（立柱中心線 X）、`bays`、
`levels:{front,back,depth}`（橫料各層中心高度）、`seats`、`expr`、`bom`。

物件對應：`w`＝系統寬、`h`＝系統深、`z`＝系統高，結構存在 `o.sys`。
`qty` 為 N 時會產生 N 個獨立物件（名稱加 `#1 #2`），依序往後錯開 60cm。

- **2D**：矩形＋各支立柱的俯視腳位（白色小方塊）
- **3D**：依 `postXs` 與 `levels` 建出真實骨架（立柱／前後橫料／深度料）。
  已驗算 272×200×34 的系統會產生 22 支桿件，與說明表備料明細完全一致
- **尺寸鎖定**：`hitHandle()` 對 system 不回傳縮放把手，避免拉伸後圖面與實際用料不符。
  要改尺寸得回說明表重新排料再匯出

## 物件類型（kind）
| 類型 | 值 | 3D 呈現 |
|---|---|---|
| 實體 | `solid` | 一整塊量體（桌、機台、柱、牆） |
| 房間 | `room` | 四面牆＋地板，中空可走進去 |
| 區域 | `zone` | 貼地薄片，用於標示走道／成品區 |
| 人形 | `person` | 比例參考人偶。2D＝肩橢圓＋頭＋面向三角形；3D＝腿/身/手臂/頭組成的人形。寬＝肩寬、深＝身體厚度、高＝身高（預設 45×35×170）。不參與漫遊碰撞、不支援分層 |

## 資料格式（存檔 JSON）
```
{ v:2, nextId, objects:[{id,name,x,y,w,h,z,rot,kind,color}],
  roomW, roomH, roomZ, bg:{src,x,y,w,h}, bgAlpha, view }
```
- `x,y` 為物件**中心**座標；`rot` 為度數
- `bg.src` 是 base64 DataURL，所以存檔會把底圖一起帶著


## 子專案 1（空間平面規劃器）：使用流程建議

> 這兩節在檔案順序上被排到「協作規則」後面，但內容屬於子專案 1。

1. Illustrator 平面圖 → 輸出 PNG
2. 右側「上傳底圖」
3. 工具列「⚖ 校正比例」沿一段已知長度（如 618cm 柱距）拉線，輸入實際 cm
4. 從左側物件庫擺放物件、調高度
5. 切到「◈ 3D 預覽」用第一人稱走一遍確認走道與空間感
6. 「💾 存檔」存成 JSON，下次「📂 讀檔」續做
