## 病因

`#app` 是上下兩塊：`#bar`（工具列，佔版面、會換行）＋ `#main`（左直條、畫面、右面板）。
工具列多一排 ⇒ `#main` 變矮、整塊往下推 ⇒ 3D 畫面的長寬比變了、模型跳一下；左直條、右面板也跟著往下移。

## 樣板與定案（kang 2026-10-14）

樣板 `樣板-工具列換行.html`：同一個假的工具列（照建模器的組數）＋ 假的畫面，切換四種做法、選 0～3 個點、換視窗寬。
平板寬度下畫面中心離頂端：A 335→381→404 每次跳；B 一直 334；C 只有第一次變高跳；D 一直 294（但要左右滑）。

| 做法 | 內容 |
|---|---|
| A 現在 | 工具列長高就把畫面往下推 |
| **B 浮在畫面上（kang 選的）** | 畫面的上緣固定在「平常的工具列高度」；多出來的排蓋在畫面上面（有陰影），模型不動 |
| C 只長不縮 | 記住長過最高的高度、不縮回去 |
| D 一排、左右滑 | 永遠一排，放不下的要左右滑 |

## 規格（B）

- `index.html`：`#bar { position:absolute }`（⛔ 再佔版面）、`#bar.over` 加陰影；`#main { margin-top: var(--barBase) }`；
  `#rail`、`#panel`（寬螢幕）的上緣內距加 `--barExtra`（內容往下讓、⛔ 被蓋住）；`#toast` 的 top 也加 `--barExtra`
- `main.js` `watchBar()`：`ResizeObserver` 盯著工具列 ——
  `--barBase` ＝ 這個視窗寬度下量過最矮的高度；`--barExtra` ＝ 現在多出來的；視窗寬度變了、工具列收合／展開 ⇒ 重新量
- ⚠ 3D 畫面右上角的 XYZ 小方向標畫在畫面裡，工具列多排時可能被蓋到一點（它只是方向提示）
- ⚠ 窄螢幕（900 px 以下，手機那種上下排的版面）⛔ 特別處理
- ⚠ `main.js`／`index.html` 的版面在測試環境跑不起來 ⇒ 靠線上看

## ⏳ 給 kang 的實測清單（2026-10-14）

⚠ 上傳之後先按一次 `抓最新版`（或 F5）。

1. **平常**：打開建模器 ⇒ 工具列一樣在最上面，畫面從它底下開始（看起來跟以前一樣）
2. **選點不跳**：方塊 → 轉成可編輯網格 → `拉點線面` → 過濾器「點」→ 開 `加選`，一個一個選點 ⇒ 工具列多一排時**模型不往下跳**；多出來的那排蓋在畫面上面、底下有陰影
3. **左右不被蓋**：同上，左邊直條最上面的按鈕、右邊面板最上面的字⛔ 被工具列蓋住（會往下讓）
4. **提示條**：選點時出現的藍色提示條⛔ 被工具列蓋住
5. **取消選取**：按 Esc 或點空白 ⇒ 多出來的排收起來，模型照樣不動
6. **收合工具列**：左下角 `工具列` 收起來 ⇒ 畫面往上長；再展開 ⇒ 回到原樣
7. **平板**：在 iPad 上也看一次第 2 項
