# 建模器：稜線看得清楚

> 起點：kang 2026-10-13 驗收曲線刀具時說「稜線在某些狀況下會很不清楚、幾乎看不到」，想要一個粗細欄位。
> kang：「我不知道哪一種方式較為合適..因為清不清楚..這種狀況我無法給你在甚麼狀況下會看不清楚的規則」⇒ 做樣板並排比，用眼睛挑。

## 病因（2026-10-14 查的）

- 稜線一律近黑色（`0x11151a`）、**半透明 0.55**、1 px ⇒ 深色物件上幾乎看不到
- 線跟面在**同一個深度**，誰畫在前面看運氣（z-fighting）⇒ 貼在面上的線（曲線刀具切的線、環切的線）一段一段被面蓋掉
- ⚠ 一般的線 `linewidth` 在瀏覽器裡沒有作用 ⇒ 只加一個粗細欄位是無效的，要換 three.js 的粗線元件（`LineSegments2`）

## 樣板與定案（kang 2026-10-14）

樣板 `樣板-稜線.html`：同一個模型（方塊頂面有曲線刀具切的圓與波浪線 ＋ 圓柱）、同一個視角並排三種畫法，可換物件顏色、調 C 的粗細。

| 畫法 | 內容 |
|---|---|
| A 現在 | 近黑、0.55、線跟面同深度 |
| B 修掉被蓋住 ＋ 加深 | 面往後讓一點（`polygonOffset`）、線不透明、顏色跟著物件深淺換 |
| C 粗線 | B ＋ 粗線元件 ＋ 粗細滑桿 |

| # | 問的事 | 定案 |
|---|---|---|
| 1 | 用哪一種 | **先 B，不夠再 C**（粗細欄位先不做）|
| 2 | 曲面上的線（圓柱側面那一條一條）| **一樣清楚**（⛔ 另外調淡）|

## 規格（B）

- `view/scene.js`：
  - 物件的面材質 `polygonOffset: true, factor 1, units 1` ⇒ 貼在面上的線永遠贏
  - 稜線材質不透明，顏色 `edgeLineColor(物件顏色)`：sRGB 亮度 ≥ 0.5 ⇒ 深線 `0x11151a`，否則淺線 `0xe8edf3`；`_updateNode()` 每次跟著物件顏色重設
  - ⚠ 亮度用 0～255 直接算，⛔ 用 `THREE.Color` 的 r／g／b（線性空間，門檻會跑掉）
- ⚠ `scene.js` 在測試環境載不進來（要瀏覽器的元件）⇒ 這一項靠線上看
