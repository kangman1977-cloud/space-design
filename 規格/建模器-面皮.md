### 規則

| | |
|---|---|
| **從哪裡按** | 分片模式、標縫那一頁、「智慧分切：提案」下面一顆「**複製成面皮**」（kang ①）；參數物件要先轉成可編輯網格（跟標縫同一個規矩）；面皮自己⛔ 有這一顆 |

| **面皮是什麼** | 開放的**板件**、同樣的位置角度縮放、顏色與板厚照原本；名字「○○ 面皮 1、2…」；裡面的折線、平滑、看得見、不准切、保持尖**連同塊裡面的縫**照搬（圓筒那一條直縫兩側在同一塊 —— ⛔ 搬就不見了，沙箱第一版撞到）|
| **放哪裡** | 新的一層「**○○ 面皮**」、跟原本疊在同一個位置（kang ②）；同名的那一層已經有 ⇒ 放那一層（再按一次⛔ 一直開新層）；目前這一層⛔ 換；原本的物件⛔ 動 |
| **板厚往哪長** | **往內長**（kang ③）：外面就在原本的面上、裡面往內一整個板厚 ⇒ 畫面上跟原本一樣大（一般板件照舊往兩邊各一半）；面皮⛔ 照「平躺在地板上往上長」那一條 |
| **出口** | 3D 列印、剖面分切、OBJ、干涉檢查**跳過面皮**（沒選東西、選了也跳）並講「（面皮 N 張是給展開用的，沒算）」（kang ④）；**展開照樣算面皮**（面皮就是給展開用的）|
| **原本的改過了** | 面皮記著原本那個物件與當時的指紋（點、面、座標、你標的切開幾條）；之後原本的拉了點、改了縫 ⇒ 面皮的物件面板黃字「⚠ 原本的「○○」改過了（形狀或縫），這張面皮是舊的 —— 要的話刪掉重新複製」；原本的刪掉了 ⇒「⚠ 原本的「○○」已經不在了，這張面皮留著當獨立的板件用」；只提醒、⛔ 自動重做（kang ⑦）|

### 怎麼做到的

- `core/io.js`：`ModelObject.skinOf`（`{ id, name, sig }`，建構子、`toJSON()` 有才存、`fromJSON()`）；`skinSig(mesh)`；`makeSkins(obj)`（照切開分塊、每塊 `Mesh.fromFaceList()`、裡面的邊 `marksOf()`／`applyMarks()` 照搬）；`sheetShell()` 面皮走 `shell(t, { inward: true })`；`Doc.forMaking(picked)`、`skinNote(picked)`、`skinState(o)`。
- `core/mesh.js` `shell(t, { inward })`：外側在原本的面上、內側往內兩個半板厚（折角照舊多推）。
- `main.js` `makeSkinsOp()`（找或開「○○ 面皮」那一層、放進去、記一步、講一句）；干涉檢查走 `doc.forMaking()` 並多講面皮。
- `ui/exportPanel.js`、`ui/objPanel.js`、`ui/slicePanel.js`：`doc.forMaking(picked)`、提醒多接 `skinNote()`。
- `ui/toolbar.js` `_skinBtn()`（分片面板）、`_skinNote()`（網格物件面板）；`view/scene.js` 面皮往內長、⛔ 往上抬；`ai/assist.js` `AI.看()` 多「面皮」；功能地圖「物件面板：複製成面皮」。

#### ⏳ 實測（kang）

1. 按「新建」→ 加「方塊」→ 物件面板「轉成可編輯網格」→ 左邊「分片」→「智慧分切：提案」→「全部接受」→ 按「複製成面皮」⇒ 上面寫「複製成面皮 3 張，放在「方塊 1 面皮」這一層…」；右邊「圖層」頁多一層「方塊 1 面皮」、裡面 3 個。
2. 「圖層」頁把「預設」那一層的 👁 關掉 ⇒ 只剩面皮，看起來跟原本的方塊一樣大（板厚往內長）；再打開。
3. 在「圖層」頁點一張面皮的名字、回「工具與屬性」⇒ 物件面板寫「這是「方塊 1」的面皮：給展開用…」；分片模式下面皮的面板沒有「複製成面皮」。
4. 什麼都不選 → 上方「3D 列印」⇒ 上面那一行寫「1 個物件…（面皮 3 張是給展開用的，沒算）」。
5. 選方塊 → 分片 →「清除全部標記」→ 確定 → 點一張面皮 ⇒ 物件面板「⚠ 原本的「方塊 1」改過了（形狀或縫），這張面皮是舊的…」；按 Ctrl+Z ⇒ 那句不見。
6. 什麼都不選 → 展開圖 ⇒ 方塊與 3 張面皮都展開（面皮之間的接合編號要等 B 批）。
